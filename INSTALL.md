# GitHub profile README fix — installation

Target: https://github.com/qlsl1198/qlsl1198 (default branch: `main`).

This package replaces the existing README with a clearer, link-verified profile and
replaces third-party GitHub stats images with local SVGs generated by GitHub Actions.

## How to install (GitHub Desktop / Terminal)

1. Clone your profile repository if needed:

   ```bash
   git clone https://github.com/qlsl1198/qlsl1198.git
   cd qlsl1198
   ```

2. Back up your old README (or rely on Git history).
3. Extract the ZIP and copy its **README.md**, **assets/**, **scripts/**, and
   **.github/** into the root of `qlsl1198/qlsl1198`. The `INSTALL.md` itself is optional.
4. Push the new content:

   ```bash
   git add README.md assets/ scripts/generate_profile_stats.py .github/workflows/profile-stats.yml
   git commit -m "Improve profile README and replace unreliable stats images"
   git push origin main
   ```

5. Open [GitHub Actions](https://github.com/qlsl1198/qlsl1198/actions), find
   **Update profile statistics**, and run it with **Run workflow**. It also runs
   when the workflow or stats script is pushed, and then daily at 00:17 UTC
   (09:17 KST).
6. On success, GitHub Actions replaces the initial "Will populate" SVGs with
   real metrics from GitHub's API and commits them. The README references local
   paths, so the third-party stats-card servers are no longer required.

## Important notes

- The workflow needs permission to write to this repository. It requests
  `contents: write` in the workflow YAML. If pushing generated images fails,
  check repository Settings > Actions > General > Workflow permissions, and
  branch protection rules.
- The action reads GitHub's public API with the built-in `${{ github.token }}`
  secret; do **not** add a personal token to README or source files.
- `Most Used Languages` measures code bytes in public, original, non-archived
  repositories — not your proficiency or time spent writing each language.
- Private repository data and private contributions are not assumed available.
- The GitHub Actions workflow has **not** been executed in your repository from
  this package's creation environment; live GitHub API behavior still needs
  first-run confirmation.
- Header, footer, and Gitanimals CTA are bundled as local SVGs. The Gitanimals
  CTA links to the live farm instead of embedding a fragile remote image.
- Badge images from img.shields.io remain external. They are optional visual
  decoration; unlike the old statistics cards, the profile's key data is local.

## Troubleshooting

- If the stats still say "Will populate", visit the Actions run logs. The
  first run must succeed before the bootstrap cards are overwritten.
- A `403 Resource not accessible by integration` while committing often means
  the installed integration or workflow does not have write permission.
- If only the language card fails, check whether the GitHub REST languages API
  is rate-limiting requests; a successful future scheduled run will retry.
- If no scheduled run appears, open Actions and click **Run workflow**. GitHub
  schedules may run late or be disabled after long inactivity.
